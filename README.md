# Sales Performance Analytics Dashboard（売上実績分析ダッシュボード）

## Project Overview（プロジェクト概要）

This project presents a sales performance analytics dashboard created with Tableau.  
The dashboard provides a clear overview of overall sales performance through key business metrics, monthly trends, product categories, regional profitability, product performance, and city-level sales.

本プロジェクトでは、Tableauを使用して売上実績を分析・可視化するダッシュボードを作成しました。  
主要KPI、月別売上推移、カテゴリー別売上、地域別利益、商品別パフォーマンス、都市別売上を一つの画面で確認できるように設計しています。

---

## Key Metrics（主要KPI）

- **Total Sales（総売上）:** ¥1,615,050
- **Total Profit（総利益）:** ¥179,746
- **Total Orders（総注文数）:** 1,200
- **Profit Margin（利益率）:** 11.1%

---

## Dashboard Visualizations（主な可視化）

- **Monthly Sales Trend（月別売上推移）**
- **Sales by Category（カテゴリー別売上）**
- **Profit by Region（地域別利益）**
- **Top Products Performance（売上上位商品）**
- **Top Cities by Sales（都市別売上ランキング）**

The dashboard was designed to make sales patterns and business performance easy to compare visually.

売上傾向や業績を視覚的に比較しやすいようにダッシュボードを構成しています。

---

## Key Insights（主な分析ポイント）

- **Electronics（電子機器）** generated the highest sales among the displayed product categories.
- **Chubu（中部地方）** recorded the highest regional profit.
- **USB-C Hub** was the top-performing product by sales.
- **Shizuoka（静岡）** recorded the highest sales among the displayed cities.

- 表示されているカテゴリーの中では、**Electronics（電子機器）**の売上が最も高くなっています。
- 地域別利益では、**Chubu（中部地方）**が最も高い結果となっています。
- 商品別では、**USB-C Hub**が最も高い売上を示しています。
- 都市別では、**Shizuoka（静岡）**の売上が最も高くなっています。
